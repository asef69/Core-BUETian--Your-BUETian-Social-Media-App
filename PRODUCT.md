# Product

## What it is
Core BUETians is a social network for the BUET community: feed, profiles, real-time chat, groups, forums, marketplace, blogs, notifications and search. React frontend (`FRONTEND/`), Django REST + Channels backend (`BACKEND/`).

## Users
BUET students, alumni and faculty, mostly on phones between classes, also on laptops in the evening. Bangladesh-based; all times are shown in Bangladesh time (Asia/Dhaka, UTC+6).

## Mode
Operate. People come to read, reply, message and trade. Scanability, consistency and speed outrank decoration. Personality lives in precise details, not in effects.

## Principles
- A premium digital campus community with its own identity. Not a Facebook, Instagram or WhatsApp copy.
- Never fake data. The UI only shows what the existing API returns; the backend contract is fixed.
- Mobile gets its own composition (bottom navigation, full-screen chat), not a squeezed desktop.
- Every screen has loading (skeleton), empty and error-with-retry states.
- Motion is short and subtle, and respects `prefers-reduced-motion`.

## Anti-references
Bootstrap-template look, rainbow gradients, glass everywhere, emoji used as icons, nested cards.
